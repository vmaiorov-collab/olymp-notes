Определения

Сумма: $\sum_{i=1}^n i = \frac{n(n+1)}{2}$. Подотрезок — элементы подряд.

Интуиция
Двигаем обе границы только вправо, и каждая проходит массив один раз.
Замечание
Здесь используется map, поэтому $O(n\log n)$.
Именно while, а не if
С if левая граница сдвинется не более чем на единицу.
Исправление
Тестовое исправление неточности.
Собственный пример
Тестовая собственная вставка.
