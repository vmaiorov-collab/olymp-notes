Задача D. Сумма НОД по парам

Прямо считать НОД для каждой пары слишком долго, поэтому для каждого числа $d$ считаем количество пар, у которых НОД равен $d$ (–). Сначала берём все пары чисел, кратных $d$; затем вычитаем пары, у которых НОД кратен $d$, но строго больше $d$ — их мы уже посчитали для больших $d$ (–). Перебор всех $d$ вместе с их кратными работает за $O(n\log n)$ (гармонический ряд) (–).

Задача G. Максимум $\gcd\cdot(\text{сумма}-\text{максимум})$ по подотрезкам

Условие. Для подотрезка массива значение равно $\gcd$ на нём, умноженному на (сумма на нём минус максимум на нём). Нужно максимизировать значение по всем подотрезкам (–).

  • Фиксируем максимум: пусть максимум достигается в позиции $t$ (при равных можно брать, например, самый правый — в этой задаче это неважно, ведь мы ищем максимум) (–).
  • Различных значений $\gcd$ у отрезков, оканчивающихся в одной позиции, не больше $\log A$. Каждое следующее $\gcd$ делит предыдущее и отличается от него, то есть как минимум вдвое меньше (–). То же верно для отрезков с общим началом.
  • Поэтому можно перебрать «слева» значение $\gcd$ и «справа» значение $\gcd$ — получится $O(\log^2 A)$ пар. Числа могут быть отрицательными, поэтому сумма отрезка — это разность префиксных сумм, и для данной пары групп нужно взять максимальную префиксную сумму справа и минимальную слева (–).
  • Как хранить группы концов с одинаковым $\gcd$. Идём по префиксу и поддерживаем стек групп: для каждого значения $\gcd$ — отрезок начал, дающих это значение. Новый элемент $a_k$ пересчитывает $\gcd$ каждой группы (две группы, ставшие равными, склеиваем); если две позиции были в одной группе, то они остаются в одной группе и после добавления нового элемента. В группе удобно хранить минимум и максимум префиксных сумм (–).

Итог лектор оценивает как $O(n\log A)$ на перебор значений $\gcd$ (–).

Оговорка. В записи не показано, как границы групп обрезаются по области, где $a_t$ действительно максимум; без такого ограничения значение «сумма минус $a_t$» переоценивает ответ. Ограничение задаётся ближайшими большими элементами слева и справа от $t$. Перебор пар групп даёт $O(\log^2 A)$ на позицию, а не $O(\log A)$, как в итоговой оценке в записи.

Задача I. Строки из букв A, B, C по числам соседних пар

Даны количества вхождений каждой пары букв как соседних символов в строке из трёх букв $A$, $B$, $C$; нужно найти количество подходящих строк по модулю (–). Для двух букв это задача из лекции: известно число переходов между блоками $A$ и $B$, а буквы «шарами и перегородками» раскладываются по блокам (–).

Теперь добавляется буква $C$. Блоки из $C$ бывают трёх видов: вставленные внутрь группы $A$ (между двумя $A$), внутрь группы $B$ и между $A$ и $B$ (в любом из двух порядков). Блок $C$ между двумя $A$ вносит поровну в пары $AC$ и $CA$, между двумя $B$ — поровну в $BC$ и $CB$ (–). Лектор: перебираем количество блоков $C$ одного вида (в разборе — между $B$) (–). Остаток пар $BC$ и $CB$ определяет блоки на переходах $B\to A$ и $A\to B$, остаток $AC$ и $CA$ — блоки внутри групп $A$ (–). Для найденного количества блоков каждого вида остаётся перемножить числа способов «шарами и перегородками» (–). После предпосчёта факториалов и обратных к ним за $O(\text{длины строки})$ время работы линейное: перебор по количеству блоков и подсчёт по формулам из лекции (–).

Задача J. Пути по сетке через достопримечательности

Нужно посетить все достопримечательности, ходя по сетке; подсчитать число способов. Сведение, которое преподаватель уже рассказывала на прошлом занятии: вместо цикла из левого верхнего угла в правый нижний считаем пары непересекающихся путей — из клетки сразу за стартом в клетку сразу перед концом (–).

  • Состояние динамики $dp[i][j]$: один путь дошёл до достопримечательности $i$, другой — до $j$, и все достопримечательности вплоть до $\max(i,j)$ посещены (–, –).
  • Порядок. На каждом шаге сумма координат растёт, поэтому достопримечательности сортируем по $x+y$ — это порядок, в котором их можно посещать (–).
  • Непересечение. Если пути пересеклись, то хвосты можно обменять местами: получатся два других пути из тех же начал, но к переставленным концам; все достопримечательности по-прежнему посещены. Значит, лишние пары — это пары путей, пришедших в конец 2 и конец 1 вместо конца 1 и конца 2, и ответ — разность двух значений динамики (–).
  • Переходы. Пусть $i\ge j$. Если $i>j+1$, то достопримечательность $i-1$ уже посещена тем же путём, и берём $dp[i-1][j]$ умноженное на число путей из $i-1$ в $i$. Если $i=j+1$, то предыдущая достопримечательность этого пути — какая-то $k\le j$; перебираем $k$ и умножаем на число путей из $k$ в $i$ (–).

Переходы первого вида стоят $O(1)$ (всего $O(n^2)$), второго — $O(n)$, но таких состояний только $O(n)$, поэтому тоже $O(n^2)$ в сумме. Итог $O(n^2)$ плюс предпосчёт факториалов для числа путей между клетками (–).
